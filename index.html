MBOptScrapers

Repositorio de Kodi con MBOptScrapers y el puente CocoScrapers.

  • repository.mboptscrapers-1.0.0.zipRepositorio — instala solo este zip; el resto se instala y actualiza desde el repositorio.

Instalación

  1. Ajustes → Sistema → Add-ons → activa Orígenes desconocidos.
  2. Ajustes → Gestor de archivos → Añadir fuente → https://mburgosortiz2.github.io/ → nómbrala MBOPT.
  3. Add-ons → Instalar desde un archivo zip → MBOPT → repository.mboptscrapers-1.0.0.zip.
  4. Add-ons → Instalar desde repositorio → MBOptScrapers Repository → Add-ons de programas → MBOptScrapers Module → Instalar.
  5. Si tu add-on de vídeo busca CocoScrapers (Umbrella, Fen…), instala también CocoScrapers bridge (MBOptScrapers) desde el mismo repositorio.
