MBOptScrapers

Add-ons de Kodi para instalar desde un archivo zip.

  • script.module.mboptscrapers-1.0.0.zipMBOptScrapers 1.0.0 — el módulo de scrapers. Instálalo primero.
  • script.module.cocoscrapers-2.0.0.zipPuente CocoScrapers 2.0.0 — para add-ons que buscan CocoScrapers (Umbrella, Fen…). Instálalo después.
  1. En Kodi: Ajustes → Gestor de archivos → Añadir fuente → https://mburgosortiz2.github.io/
  2. Add-ons → Instalar desde un archivo zip → elige la fuente → instala los dos zips en este orden.
